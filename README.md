# 0ld_Y0uTub3

Ностальгический клон YouTube в дизайне 2008–2012 годов: красная шапка с белым логотипом, классический плеер, старые миниатюры 160x120 (4:3), комментарии, лайки/дизлайки, подписки и поиск. Без Shorts, без нового дизайна.

## Возможности

- Главная: свежие видео + блок «Most Viewed»
- Страница видео: плеер, просмотры, лайки/дизлайки, описание, комментарии, похожие видео, «More From: канал»
- Каналы: профиль, подписка/отписка, список видео, страница всех каналов
- Поиск по названию, описанию и тегам
- Все видео с сортировкой (Дата / Просмотры / Канал) и пагинацией
- Регистрация/вход (пароли хэшируются scrypt), загрузка видео до 100 МБ
- Миниатюры автоматически вырезаются из видео через ffmpeg (если нет — заглушка)
- Лента подписок

## Технологии

- Node.js + Express (server-side рендеринг на EJS — как в старом YouTube)
- SQLite (better-sqlite3) локально / PostgreSQL на Render
- Multer для загрузки файлов, cookie-session для сессий
- ffmpeg-static для генерации миниатюр

## Запуск локально

Нужен Node.js 18+.

```
npm install
npm start
```

Открой http://localhost:3000. БД, загруженные видео и миниатюры лежат в `data/` (создаётся автоматически, в git не попадает).

## Деплой на Render (бесплатно)

1. Создай публичный репозиторий на GitHub и загрузи туда этот проект.
2. Зарегистрируйся на https://render.com и войди.
3. Нажми **New → Blueprint** и подключи свой GitHub-репозиторий.
4. Render сам прочитает `render.yaml` и создаст:
   - Web Service (бесплатный план) — само приложение,
   - PostgreSQL (бесплатный план) — базу данных,
   - Persistent Disk 1 ГБ — для хранения видео.
5. Нажми **Apply**. Через несколько минут сервис поднимется, URL будет вида `https://0ld-youtube.onrender.com`.

### Переменные окружения (заполнятся сами, но можно поменять)

| Переменная | Описание |
|---|---|
| `SESSION_SECRET` | Секрет сессий (генерируется автоматически) |
| `DATABASE_URL` | Ссылка на PostgreSQL (подставляется от Blueprint) |
| `MAX_FILE_MB` | Лимит размера видео, по умолчанию 100 |

### Важно про бесплатный тариф

- Сервис «засыпает» после ~15 минут без трафика; первая загрузка страницы после простоя занимает до минуты.
- 512 МБ RAM. Persistent Disk на бесплатном тарифе недоступен, поэтому загруженные видео хранятся на временном диске сервиса: они переживают «засыпание», но пропадают при передеплое. База данных (аккаунты, комментарии, лайки) хранится в PostgreSQL и не теряется. Для учебного проекта это ок.

## Структура

```
src/
  server.js   — все роуты, запуск
  db.js       — слой БД: SQLite локально, PostgreSQL на Render
  auth.js     — scrypt-хэширование паролей, валидация
  thumb.js    — вырезание миниатюр ffmpeg
views/        — EJS-шаблоны (header, watch, home, channel, ...)
public/       — style.css, favicon, заглушка миниатюры
render.yaml   — конфигурация деплоя на Render
data/         — БД, видео и миниатюры (создаётся в рантайме)
```
