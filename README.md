# 0ld_Y0uTub3

Ностальгический клон YouTube в дизайне 2008–2012 годов: красная шапка с белым логотипом, классический плеер, старые миниатюры 160x120 (4:3), комментарии, лайки/дизлайки, подписки и поиск. Без Shorts, без нового дизайна.

## Возможности

- Главная: свежие видео + блок «Most Viewed»
- Страница видео: плеер, просмотры, лайки/дизлайки, описание, комментарии, похожие видео, «More From: канал»
- Каналы: профиль, подписка/отписка, список видео, страница всех каналов
- Поиск по названию, описанию и тегам
- Все видео с сортировкой (Дата / Просмотры / Канал) и пагинацией
- Регистрация/вход (пароли хэшируются scrypt), загрузка видео до 100 МБ
- Миниатюры автоматически вырезаются из видео через ffmpeg (если нет — заглушка)
- Лента подписок

## Технологии

- Node.js + Express (server-side рендеринг на EJS — как в старом YouTube)
- SQLite (better-sqlite3) — и локально, и в облаке (PostgreSQL — опционально через `DATABASE_URL`)
- Multer для загрузки файлов, cookie-session для сессий
- ffmpeg-static для генерации миниатюр

## Запуск локально

Нужен Node.js 18+ (рекомендуется 22).

```
npm install
npm start
```

Открой http://localhost:3000. БД, загруженные видео и миниатюры лежат в `.data/` (создаётся автоматически, в git не попадает).

## Деплой на Glitch (бесплатно, без банковской карты)

1. Зарегистрируйся на https://glitch.com (можно через GitHub).
2. Нажми **New Project → Import from GitHub**.
3. Вставь ссылку на репозиторий: `https://github.com/John-Davey-Harris-073/0ld_Y0uTub3`
4. Glitch сам установит зависимости и запустит приложение. Через 1–2 минуты проект заработает по адресу `https://<имя-проекта>.glitch.me`.
5. Задай секрет сессий: в проекте открой **Tools → Terminal** (или файл `.env` в редакторе) и добавь:
   ```
   SESSION_SECRET=любая-длинная-случайная-строка
   ```
   После этого перезапусти проект (кнопка **Restart** в меню проекта).

### Важно про бесплатный тариф Glitch

- Проект «засыпает» после ~5 минут без посетителей; при заходе просыпается за несколько секунд.
- Хранилище 400 МБ — папка `.data` постоянная, база и видео не теряются при перезапуске.
- Лимит ~1000 часов работы в месяц — при редких заходах хватает с запасом.

## Альтернатива: деплой на Render (бесплатно)

1. Нажми **New → Blueprint** на https://render.com и подключи репозиторий (`render.yaml` в корне).
2. Если на аккаунте уже есть бесплатная база данных — укажи её URL в переменной `DATABASE_URL` сервиса (вкладка Environment), а из `render.yaml` база убрана намеренно: бесплатный тариф разрешает только одну БД на аккаунт.
3. Переменные окружения: `SESSION_SECRET` (генерируется автоматически), `MAX_FILE_MB` (по умолчанию 100).
4. На free-тарифе видео хранятся на временном диске и пропадают при передеплое (Persistent Disk недоступен); сервис засыпает после ~15 минут простоя.

## Структура

```
src/
  server.js   — все роуты, запуск
  db.js       — слой БД: SQLite по умолчанию, PostgreSQL при наличии DATABASE_URL
  auth.js     — scrypt-хэширование паролей, валидация
  thumb.js    — вырезание миниатюр ffmpeg
views/        — EJS-шаблоны (header, watch, home, channel, ...)
public/       — style.css, favicon, заглушка миниатюры
render.yaml   — опциональная конфигурация для Render
.data/        — БД, видео и миниатюры (создаётся в рантайме, постоянна на Glitch)
```
